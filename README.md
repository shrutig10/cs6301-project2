# CS 6301 Project 2

CIFAR-10 image classification using convolutional neural networks
and residual learning.

## Planned experiments

- Implement and verify a baseline CNN.
- Compare training with and without data augmentation.
- Compare a plain deep CNN with a residual CNN.
- Select a final configuration using validation results.
- Evaluate the selected configuration on the test set.

## Reproducibility

- Dataset split seed: 42
- Training examples: 45,000
- Validation examples: 5,000
- Comparison training seeds: 0, 1, 2
